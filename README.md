# End-To-End-Blog-Generation-Gen-AI-Using-AWS-Lambda-And-Bedrock-GenAI-Project
This Repository contains my working files on "End To End Blog Generation Gen AI Using AWS Lambda And Bedrock Project", an GenAI Project

(i) Set up a fully serverless Python environment with AWS Lambda, Amazon API Gateway, and Boto3, including proper virtual environment, dependencies, and Lambda layer configuration for updated packages.

(ii) Developed a Lambda function to interact with Amazon Bedrock foundation models to generate content dynamically based on user queries.

(iii) Created an API using Amazon API Gateway to accept POST requests with a blog topic, triggering the Lambda function for on-demand blog generation.

(iv) Implemented automated storage of generated content in Amazon S3 with timestamped filenames, ensuring easy retrieval and organized storage of outputs.

(v) Built a scalable and modular generative AI workflow combining API Gateway, Lambda, Bedrock foundation models, and S3 storage, enabling a fully end-to-end blog generation application leveraging AWS services efficiently.
